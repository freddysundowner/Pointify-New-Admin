- [List normalization contract](list-normalization-contract.md) — proxy normalizes all lists to {data,count,totalPages,currentPage}; spec wrapper schema + page `.data` access must match.
- [Upstream analytics endpoints](upstream-analytics-endpoints.md) — use /subscriptions/shop/stats for trial/active counts (NOT /shop/stats/metrics, which lies); upstream source is in attached_assets/.
- [Upstream admins endpoint](upstream-admins-endpoint.md) — upstream `name` searches username/email/phone; NO date filter (proxy filters createdAt in EAT); strip leaked `password` hashes.
- [Responsive list-page pattern](responsive-list-pages.md) — admin-panel list pages: desktop `<Table>` (hidden md:block) + mobile card list (md:hidden) from same data; keep both in sync.
- [Shops list upstream constraints](shops-list-upstream.md) — /shop/ supports name/status/type/ownerid only; owner projected to email+phone (no name); count needs totalShops.
- [Upstream shop-filter params](shop-filter-params.md) — each list endpoint uses a different key (products=shopid, sales/purchases/attendants=shopId, subscriptions=shop); wrong name silently returns the full list.
- [Pointify products upstream](pointify-products-upstream.md) — admin list uses /product/admin/products (name/shop/shopid); products have no updatedAt (only `date`); batches only via getProductById.
- [Orval params name collision](orval-params-collision.md) — never mix a path param + required query params in one spec path; pass id as a query param to avoid a zod/type `<Op>Params` clash that breaks api-zod codegen.
- [Admin edit-form semantics](admin-edit-forms.md) — edit forms: text sends "" to clear, numbers omit when blank, category refs send null to detach (nullable spec); category lists are global.
